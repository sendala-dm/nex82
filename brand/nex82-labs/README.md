# NEX82 Labs logo

NEX82 wordmark with a smaller, centred LABS line in the existing Neo Latina brand font. The main wordmark uses the same font outlines and matches the existing glyph positions and proportions.

- `nex82-labs-white.svg`: white, transparent background.
- `nex82-labs-navy.svg`: navy #142438, transparent background.
- Matching transparent PNGs: 2880 × 1100 pixels.
- SVG lettering is converted to paths; no font installation is needed to use the logo.
- `preview.html` / `preview.png`: examples on dark and light backgrounds.

Rebuild vector assets with Python + fonttools: `python build_logo.py /path/to/neo-latina.otf`. PNGs are rendered from the SVGs at 2× scale.
